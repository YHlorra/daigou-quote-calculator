## 这是什么

一个给海外代购 / Personal Shopper 用的报价工具。它不是汇率换算器——换算只是第一步，它把整条报价链走完：

汇率快照 → 汇率缓冲 → 采购成本（含境内运费、其他成本）→ 服务费（费率与最低收费取高）→ 平台手续费毛加价 → 建议报价（可取整）→ 预计利润。

纯静态 PWA：没有后端、没有账号，计算全部在浏览器本地完成，添加到主屏幕后离线也能用。支持 JPY / USD / EUR / GBP / KRW / HKD / TWD / SGD / AUD / CAD / PHP / CNY 共 12 种币种，结算货币不写死。

## 为什么造这个

每次给客户报价，我都得在计算器里按一长串：市场汇率、往上加点缓冲、境内运费换算、服务费不足 10 块按 10 块算、平台还要从成交额里抽成——这意味着报价不能直接乘，得倒推（除以 1 减费率）。中间一步算错，就是自己贴钱。

市面上的工具要么只是个汇率换算器，要么绑死在某个平台里。所以我把自己的报价习惯做成了这个工具：所有费率可调、可以存成方案一键切换，算完一键复制发给客户。写给我自己用，也写给同样在代购群里手动算价的人。

## 核心能力

- ✅ **输入即算**：改任何参数，报价面板 300ms 内实时刷新，不用点按钮
- ✅ **完整费率模型**：汇率缓冲、最低服务费（两者取高不叠加）、平台手续费毛加价（÷(1−费率) 倒推）、四档报价取整
- ✅ **收费方案 Presets**：内置闲鱼代购 / 熟人价 / 高价商品 / 抢购商品，可另存自定义方案，localStorage 持久化
- ✅ **汇率快照**：er-api 主源 + frankfurter 备源，每日更新，如实标注来源与时间（不称「实时」）；打开页面 / 切币种自动对齐，手改过的汇率不被覆盖
- ✅ **离线可用**：断网照样算，快照用上次缓存值
- ✅ **一键复制**：报价明细直接粘贴发给客户

## 报价公式

```
实际汇率 = 汇率 × (1 + 汇率缓冲)
采购成本 = 商品价×实际汇率 + 境内运费×实际汇率 + 其他成本
服务费   = max(采购成本×服务费率, 最低服务费)        ← 两者取高，不叠加
报价     = (采购成本 + 服务费) ÷ (1 − 平台手续费率)   ← 毛加价：平台从成交额抽成，须倒推
利润     = 报价 − 采购成本 − 报价×平台手续费率
```

## 已知边界

**适合：**
- ✅ 个人代购 / 小团队给客户快速报价
- ✅ 多平台、多收费方案并存的代购业务

**不太适合：**
- ❌ 多端同步、团队协作——没有账号系统，数据只存在本机 localStorage
- ❌ 财务对账、多币种记账——它只管报价，不做账本

### 汇率来源说明

汇率来自 **er-api**（每日更新一次的免费快照）与 **frankfurter**（备用，不含 TWD / PHP），页面如实标注来源与更新时间，不声称「实时」。实际成交汇率以你的支付通道为准，建议保留 1–3% 的汇率缓冲对冲价差。
